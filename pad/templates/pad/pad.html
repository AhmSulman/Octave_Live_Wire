Time model ▶
All durations are in beats.
Internally converted to seconds: sec = beats × (60 / bpm)

At BPM 120: 1 beat = 0.5 s · 4 beats (whole note) = 2 s
At BPM 60 : 1 beat = 1.0 s · 4 beats = 4 s

Cursor rules:
• play_note / play_chord / rest → advance cursor
• play_drum → overlay at cursor, does NOT advance
• rewind() → jump to 0 · rewind(n) → back n beats
• set_time(n) → jump to beat n

Multi-track: each track has its own independent cursor. Arm multiple tracks to play them simultaneously.
Examples ▶
Scale run
set_bpm(120) for i in range(8): play_note(i, eighth_note)
Chord progression
set_bpm(90) set_instrument('piano') for root in [0, -3, -5, -2]: play_chord([root, root+2, root+4], half_note)
Drums + melody (same track)
set_bpm(120) melody = [0, 2, 4, 2, 0, -3, 0, 2] for i, step in enumerate(melody): if i % 2 == 0: play_drum(0) # kick on even beats else: play_drum(1) # snare on odd play_note(step, Q)
Loop + variation
set_bpm(110) set_instrument('pluck') pattern = [0, 4, 7, 4] for repeat in range(4): for step in pattern: vel = 110 if repeat == 3 else 75 play_note(step, S, velocity=vel) rest(Q)
Drum groove (Track 2)
set_bpm(120) for beat in range(8): play_drum(0) if beat % 4 == 0 else None play_drum(1) if beat % 4 == 2 else None play_drum(2) # hi-hat every beat rest(Q)
Named notes + rewind
set_bpm(100) motif = [note('E4'), note('G4'), note('A4'), note('G4')] for step in motif: play_note(step, E) rewind(len(motif) * 0.5) set_instrument('pad') play_chord([0, 4, 7], half_note, velocity=55)
Strum + arpeggio
set_bpm(100) set_instrument('pluck') for root in [0, -3, -5, -2]: strum([root, root+2, root+4, root+7], H, gap=0.05) arpeggio([root, root+4, root+7], S, style='updown')
Beethoven 5th — EDM remix
# Beethoven Symphony No.5 — first motif, EDM style set_bpm(138) humanize(timing=0.008, velocity=6) # The famous 3-short-1-long motif in Eb minor (public domain) motif = [note('G4'), note('G4'), note('G4'), note('Eb4')] set_instrument('synth') for repeat in range(4): for i, n in enumerate(motif): dur = whole_note if i == 3 else eighth_note vel = 110 if i == 3 else 95 play_note(n, dur, velocity=vel) if repeat < 3: rest(E) # Second phrase: F minor answer answer = [note('F4'), note('F4'), note('F4'), note('D4')] for i, n in enumerate(answer): dur = dotted_half if i == 3 else E play_note(n, dur, velocity=100 if i == 3 else 90)
Echo + trill
set_bpm(90) set_instrument('piano') set_scale('A', 'minor') echo(0, Q, velocity=100, times=3, decay=0.5, gap_beats=Q) rest(W) trill(4, 5, total_duration=H, note_duration=S) rest(Q) play_chord([0, 2, 4], H, velocity=80)
Transpose modulation
set_bpm(120) set_instrument('synth') set_scale('C', 'pentatonic_minor') phrase = [0, 1, 2, 4, 3, 1, 0] for semitone_shift in [0, 5, 7, 12]: transpose(semitone_shift) for step in phrase: play_note(step, E) rest(Q) transpose(0)
